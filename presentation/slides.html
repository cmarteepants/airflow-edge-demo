The Edge Executor

Airflow Server
Scheduler queues tasks
Serves API over HTTPS
Stores state in metadata DB
← HTTPS → "Got anything
for me?" pull, not push
Edge Worker
Polls for jobs
Executes locally
Reports results back

No Kafka. No RabbitMQ. No Kubernetes. No open inbound ports.
If your device can make an HTTPS request, it can be an edge worker.

Section 05 — The Python

The DAG — 63 lines

@dag(
    schedule="@continuous",   # loop forever
    max_active_runs=1,        # one meeting at a time
    start_date=datetime(2026, 3, 1),
)
def led_sign():
    (wait_for_meeting_start()
     >> set_on_air()
     >> wait_for_meeting_end()
     >> set_free())

@continuous + max_active_runs=1 = event loop.
Each DAG run is one meeting lifecycle.
Four tasks in a line: wait, act, wait, act.

11 / 17

The entire Zoom detection logic

def is_in_meeting() -> bool:
    result = subprocess.run(
        ["pgrep", "-x", "CptHost"],
        capture_output=True,
    )
    return result.returncode == 0

No API key. No OAuth. No webhook server. Just pgrep.

CptHost is Zoom's meeting process on macOS. Present when you're in a call, gone when you're not. Works offline. At a conference, you can't trust WiFi for API calls.

12 / 17

Decouple tasks from hardware

Airflow Task
writes JSON
exits immediately
→
State File
/tmp/led-state.json
→
LED Service
reads JSON
drives GPIO

The LED library holds GPIO while running. If the Airflow task tried to drive the display, it would never exit.

Airflow tasks should be ephemeral. If your task can't finish, decouple.

Section 06 — Lessons

Design Principles

Pull beats push for constrained environments

No open ports, no VPN. The Pi reaches out over HTTPS. Works behind NAT, on conference WiFi.

Simple beats clever

pgrep over Zoom API. Flag file over Kafka. The dumbest thing that works is the most reliable thing on stage.

14 / 17
Section 06 — Lessons

Practical Realities

Decouple tasks from resources they can't own

Write state, exit. Let a separate service hold the hardware. Applies to GPUs, serial ports, GPIO.

Airflow on a Pi is... a lot

416MB RAM + swap. It works, but a thin edge runtime is a known gap. This is a demo, not production IoT.
